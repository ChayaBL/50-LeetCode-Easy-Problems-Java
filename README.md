# 50 LeetCode Easy Problems – Java

All 50 Java solutions are kept directly in this single folder (no subfolders).

- 50 numbered `.java` files
- LeetCode-style `class Solution` format
- Beginner-friendly implementations
- Time and space complexity notes in each file

Open a problem file and copy its `Solution` class into the matching LeetCode editor. LeetCode supplies helper types such as `ListNode` where required.
